Tyler's Pet Palace

Tyler's Pet Palace is a C++ pet shop simulator that allows customers to browse different categories of pets, add pets to a shopping cart, and make purchases using a randomly generated budget. This project was designed to combine multiple programming concepts into one interactive application.

Key Features

  • Interactive menu with multiple pet categories.
  • Randomized pet selections and customer budget.
  • Input validation to handle incorrect menu selections.

What I Learned

One challenge I faced while developing Tyler's Pet Palace was adding new features without breaking parts of the program that were already working. Testing and debugging each feature as I added it helped me solve problems and better understand how multiple classes and functions work together. This project also improved my understanding of object-oriented programming, input validation, and oranizing a larger C++ program.
